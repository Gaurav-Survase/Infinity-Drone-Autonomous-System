🚀 Infinity Drone – Autonomous Navigation System
📌 Overview
Infinity Drone is a fully autonomous intelligent drone system developed using Raspberry Pi and Python.
The drone performs automatic path planning using onboard downloaded maps and navigates to a target destination without human intervention.
The system continuously scans the environment, detects obstacles in real time, and dynamically recalculates a new safe path if an obstruction is detected. It supports both fully autonomous operation and manual override mode for enhanced flexibility and safety.
